# CS361 Teaching Compensation Claim System
Demo repositort for Project Grill and Boundary Grill

Project Vision

ระบบกลางสำหรับจัดการการเบิกค่าตอบแทนการสอนและค่าตอบแทนที่เกี่ยวข้อง รองรับอาจารย์/ผู้สอน ผู้ช่วยสอน (TA) และผู้มีสิทธิ์ประเภทอื่นที่อาจเพิ่มขึ้นในอนาคต ระบบจะค่อย ๆ พัฒนาความสามารถจากการนำเสนอข้อมูล ไปสู่การยื่นคำขอ ตรวจสอบ อนุมัติ และบริหารจัดการแบบครบวงจรตลอด V1–V7

Primary User

อาจารย์ / ผู้สอน 

Problem

    อาจารย์/ผู้สอนไม่แน่ใจว่าตนมีสิทธิ์เบิกค่าตอบแทนประเภทใดได้บ้าง อัตราเท่าไร ต้องเตรียมเอกสารอะไร และขั้นตอนเป็นอย่างไร เนื่องจากข้อมูลกระจายอยู่ในหลายแหล่ง เช่น ประกาศของคณะ เอกสารกระดาษ หรือต้องสอบถามเจ้าหน้าที่โดยตรง

Current Situation

    อาจารย์ต้องตรวจสอบข้อมูลจากหลายช่องทาง (ประกาศ, เอกสารเวียน, ถามเจ้าหน้าที่) ทำให้เสียเวลาและบางครั้งได้ข้อมูลไม่ครบหรือไม่เป็นปัจจุบัน

Desired Outcome

    อาจารย์สามารถเข้าถึงข้อมูลค่าตอบแทน อัตรา เงื่อนไข และเอกสารที่ต้องใช้ ได้จากที่เดียว โดยไม่ต้องรอถามเจ้าหน้าที่

V1 Goal

    อาจารย์/ผู้สอนสามารถดูข้อมูลพื้นฐานเกี่ยวกับค่าตอบแทนการสอนและค่าตอบแทน ที่เกี่ยวข้องได้จากระบบเดียว โดยยังไม่ต้องเข้าสู่ระบบหรือยื่นคำขอผ่านระบบ

V1 In scope
    แสดงประเภทค่าตอบแทนที่อาจารย์/ผู้สอนมีสิทธิ์เบิก
    แสดงอัตราและหลักเกณฑ์ของแต่ละประเภท
    แสดงเอกสารประกอบที่ต้องเตรียม
    แสดงขั้นตอนการเบิกโดยรวม (ภาพรวมกระบวนการ)
    ค้นหา/กรองข้อมูลประเภทค่าตอบแทนเบื้องต้น

V1 Out of scope
    การสร้าง บันทึกร่าง หรือยื่นคำขอเบิกจริง
    การเข้าสู่ระบบ (Login) และการแบ่งสิทธิ์ตามบทบาท
    Workflow การตรวจสอบและอนุมัติ
    การคำนวณยอดเบิกอัตโนมัติ
    การแจ้งเตือนหรือติดตามสถานะคำขอ
    ข้อมูลเฉพาะของผู้ช่วยสอน (TA) หรือผู้มีสิทธิ์ประเภทอื่น (พิจารณาใน V2)

External actors / systems
    เจ้าหน้าที่ / ผู้ตรวจสอบ, ผู้อนุมัติ, ผู้บริหาร — จะกลายเป็นผู้ใช้งานระบบจริงตั้งแต่ V3 เป็นต้นไป
    ระบบภาระงานสอน/ตารางสอนของมหาวิทยาลัย — แหล่งข้อมูลอ้างอิงในอนาคต
    ระบบการเงิน/เบิกจ่ายของมหาวิทยาลัย — ปลายทางที่ข้อมูลอาจต้องส่งออกไปในอนาคต
    
Open questions / To validate
    อัตราค่าตอบแทนเปลี่ยนแปลงบ่อยแค่ไหนในแต่ละภาคการศึกษา
    อาจารย์ต้องการเห็นข้อมูลอะไรมากที่สุดก่อนตัดสินใจยื่นเบิก (อัตรา, เอกสาร, หรือกำหนดเวลา)
    ควรรวมข้อมูลของผู้ช่วยสอน (TA) ไว้ในหน้าเดียวกันหรือแยกหน้าตั้งแต่ V1
